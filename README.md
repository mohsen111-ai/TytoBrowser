# TytoBrowser

Minimalist Android web browser using Jetpack Compose and Mozilla GeckoView.

## Build
GitHub Actions installs Gradle 8.5, generates the wrapper, and runs `./gradlew assembleDebug`. The debug APK is uploaded as a workflow artifact.

## Design
Obsidian `#08080A`, gunmetal `#141419`, crimson `#FF1E38`, white `#FFFFFF`, silver `#9EA3B0`, with clean vector geometry and subtle crimson borders.
